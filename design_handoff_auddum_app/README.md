# Handoff: 어떰? (AuDDum) — 모바일 웹 앱

## Overview
20–30대를 위한 연애 고민 투표 앱. 사용자가 고민을 올리면 다른 사람들이 선택지 중 하나를 골라 "답장"하고, 투표 후 결과(%)를 본다.
핵심 흐름: 홈 피드(카테고리 필터) → 고민 상세 → 하나 선택 → 제출 → 결과. 로그인 없이 투표 가능, 고민 작성은 카카오 로그인 필요.

## About the Design Files
`reference/` 안의 파일은 **HTML로 만든 디자인 레퍼런스(프로토타입)** 입니다. 의도한 모양과 동작을 보여주는 용도이며 **그대로 복사해 배포할 프로덕션 코드가 아닙니다.**
목표 코드베이스의 기존 환경(React/Next.js, Vue, 네이티브 등)과 패턴·라이브러리로 **다시 구현**하세요. 코드베이스가 없다면 모바일 웹에 적합한 프레임워크(권장: Next.js + TypeScript)를 골라 구현하세요.
`.dc.html` 파일은 브라우저에서 바로 열립니다 (`support.js`와 같은 폴더에 있어야 함).

## Fidelity
**High-fidelity.** 색·타이포·간격·라운드·모션·문구가 최종값입니다. 아래 토큰과 문구를 그대로 사용하세요.

| 눌림(press) | 모든 버튼·행·칩·말풍선 `:active { transform: scale(.97) }`, transition `.14s ease` |
| 화면 진입 | `@keyframes up` — `opacity 0→1, translateY(14px→0)`, .34s `cubic-bezier(.2,.8,.2,1)`, `both` |
| 하단 CTA 진입 | 동일 up, .3s ease |
| 시트 | 위 참조 (.3s / 딤 .2s) |
| 결과 막대 | `scaleX(0→1)`, origin left, .7s, 항목당 90ms stagger |
| 말풍선 선택 | scale 1→1.03, .22s `cubic-bezier(.3,1.5,.5,1)`, 배경/글자색 .18s |
| 토스트 | .3s, 2.6초 유지 |

`prefers-reduced-motion`에서는 translate/scale 모션을 제거할 것(프로토타입엔 없음 — 추가 권장).

### 토스트·에러 문구 (그대로 사용)
- 투표: "답장이 전달됐어요" / 미선택 "답장을 하나 골라주세요" / 정지 "이용이 정지된 계정이라 참여할 수 없어요" / 마감 레이스 "방금 마감됐어요 · 새 참여는 막혀요 (POLL_CLOSED)"
- 작성: "올렸어요 · 바로 공개됐어요" / "이용이 정지된 계정이라 올릴 수 없어요" / "조금 있다가 올려주세요 · 연속 작성 간격 제한 (429)" / "직전과 같은 고민이에요 (409)"
- 삭제: "삭제했어요 · 복구할 수 없어요" / 신고: "신고가 접수됐어요 · 관리자가 검토해요" / "신고 사유를 골라주세요" / "이미 신고한 고민이에요 (409)" / "이용이 정지된 계정은 신고할 수 없어요"
- 계정: "로그아웃했어요" / "탈퇴했어요" / "가입했어요 · 환영해요!" / 정지 선택 시 "이용이 정지된 계정이에요 (MEMBER_SUSPENDED)"
- 괄호 속 코드(`POLL_CLOSED`, `429`, `409`, `MEMBER_SUSPENDED`)는 프로토타입 설명용 — **실제 UI에는 노출하지 말고 서버 에러 코드로 매핑**해 괄호 앞 문구만 표시.

## 비즈니스 규칙 / API 응답 규칙
- **투표**: 1인 1회, 제출 후 변경·취소 불가. 마감된 글은 `POLL_CLOSED`로 거절. 마감 시각 경과는 **서버 시각 기준**(클라이언트는 응답으로 판단 → "방금 마감됐어요" 토스트 후 마감 UI로 전환).
- **결과 노출**: 참여했거나 마감된 글만 퍼센트 노출. 미참여·진행 중에는 응답에 퍼센트/득표수를 **포함하지 말 것**(서버에서 차단). 단, 참여 인원수(총합)는 공개.
- **퍼센트**: `Math.round(votes[i] / total * 100)` — 합이 100이 아닐 수 있음(허용).
- **비회원 투표**: 브라우저 단위 익명 토큰(쿠키/localStorage)으로 중복 방지, "참여한 고민"은 그 토큰 기준. 로그인하면 기존 참여 기록을 계정에 연결할지 정책 결정 필요.
- **작성 제한**: 본문 1–500자(줄바꿈 제거), 선택지 2–5개·각 1–50자·중복 불가, 카테고리 1개 필수, 마감 `없음|1h|24h|3d`. 연속 작성 간격 30초(`429`), 직전과 동일 본문 `409`. 즉시 공개, 수정 불가, 삭제만 가능.
- **삭제**: soft delete(복구 불가 UI, 데이터는 보존). 참여 기록 보존. 삭제된 글은 상세 접근 시 not-found 화면.
- **신고**: 사유 5종(기타는 ≤100자). 같은 사용자의 같은 글 중복 신고 `409`. 신고 수로 자동 숨김/삭제하지 **않음**. 상태: `대기 → 기각 | 숨김 처리 | 삭제 처리`, 처리 이력(처리자·시각·작성자 정지 여부) 저장. 신고자에게 결과 알림 없음.
- **숨김**: 작성자 본인은 열람 가능(내 고민에 "숨김" 표시), 타인에겐 노출 안 됨. 복구 가능.
- **피드**: 최신순 + 카테고리 필터(서버 쿼리 `category`), 커서/페이지 기반 "더 보기". 지금 인기 = 진행 중인 글 총 투표수 상위 3.
- **탈퇴**: 계정 삭제, 올린 고민은 작성자 없이 유지, 투표 기록 보존. 같은 카카오 계정 재가입 시 새 계정.
- **인증**: 카카오 OAuth. 최초 로그인 시 약관 2종(필수) 동의 → 가입 완료.

## State Management (프로토타입 state → 실제 상태)
